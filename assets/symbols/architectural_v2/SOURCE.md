# Source and provenance

Imported from the user-provided `Vertex_Architectural_SVG_Library_v2.zip`.

- Archive SHA-256: `bb0c38b74e9b5a2073d016352d03c5c05aca1e354de773f75cf52569064dbe0b`
- Source library: Vertex Architectural SVG Library, index version 2.0.
- 320 SVG documents, 25 categories, plus the original README and JSON/CSV indexes.
- The original archive is retained externally by the project owner. The 320
  imported SVG identities, geometry, viewBoxes and nominal dimensions are
  preserved, but the working assets are no longer byte-for-byte archive copies.
- At the user's direction, the imported SVGs were restyled with white surfaces,
  black structural outlines and restrained light-gray shading. Semantic dark
  apertures and subordinate highlights remain distinct. The deterministic
  migration is `scripts/restyle_architectural_svg_library.py`.
- Two first-party overhead wall cabinets (600 × 350 and 900 × 350 mm) supplement
  the archive using dashed footprints and single/paired door divisions. At that
  checkpoint, the indexed library contained 345 symbols in the original 25 categories.
- `catalog_data.inc` is derived metadata generated by
  `scripts/generate_architectural_svg_catalog.py`.
- The archive supplied no separate license file. The Vertex project owner
  explicitly directed that this collection be included in the public,
  GPL-3.0-or-later Vertex repository as first-party project assets. This record
  documents that project authorization and archive identity; it does not make a
  representation about rights held by any unidentified third party.

240 SVG descriptions specify nominal footprint dimensions in millimetres. The
other 112 provide no physical dimensions; their catalog sizes are editable
defaults, not measured dimensions. SVG viewBoxes are rendering coordinates and
must not be interpreted as physical dimensions by themselves.
