# Independent appraisal area copies

Clone and Copy/Paste now include an area's required deductions, recorded source
walls, hosted openings, associated dimensions, internal constraints and owned
appearance. Fresh identities and one common rigid transform keep these objects
independent of the originals. Canonical source geometry and deduction containment
are validated before one reversible document command is published.

Dragging a selected parent previews and moves its required geometry together.
Mixed selections share the same captured-source preprocessing for model objects,
symbols, text and reference overlays. Preview cancellation and revision/serial
checks remain intact. Copy admission rejects stale sources, external locked
relationships and incomplete payloads that would attach a pasted object or
appearance to an original owner. Ordinary standalone annotation workflows remain
supported. Deductions may retain separate layers on the same property/building/floor,
matching the existing Auto-Subtract ownership rule.

## Observed verification

- The original native reproduction failed because a cloned parent retained the
  original garage ID. No calculation validation was weakened to make it pass.
- Eight actual native cases cover Imperial/Metric, drawn/wall-derived areas and
  residential/light-commercial declarations. They verify exact net and category
  totals, independent deduction edits, 90-degree clones, current physical sources,
  styled hosted windows, separate deduction layers, parent-only clipboard actions,
  complete transient previews, atomic Undo/Redo and native save/reopen.
- A tampered clipboard opening targeting an original unrelated wall refuses
  without changing entities, revision, history or document digest. Missing source
  walls refuse both Clone and Copy without a partial result.
- Native mixed drags cover measured areas, an ordinary boundary, wall, symbol,
  text and reference image, including preview, fractional distances, cancellation,
  conflicting partial selections, named-plan coordinate conversion and reopening.
  The image import sandbox was unavailable in this test environment: the fixture
  verified that rejection, then used a trusted embedded raster to isolate reference
  editing. This is not import certification.
- Release build, focused copies, full desktop exterior measurement, annotation
  clipboard, connected-wall motion, batch boundary clone, canvas and appraisal
  calculation checks passed. Requirement contract and diff checks passed.
- Independent review found closure, fresh-reference admission, mixed preview,
  appearance and resolved-context issues. These were corrected and the affected
  checks rerun. Root reviewed the integrated changes and rendered native captures.

The checks also exposed fixture errors: an off-canvas drag endpoint, comparisons
of joined overlapping wall outlines instead of analytical baselines, an old error
interrupting an asynchronous wait, and a retained label displacing a resize handle.
Those fixtures were corrected without relaxing product admission or calculation
checks. Preview wall snap geometry now follows the candidate baseline too.

## Limits and delivery

An existing area with deductions/source walls can translate as a group, but its
in-place rotation/reflection still refuses explicitly; an independent Clone can
rotate/reflect. Fixed-point wall locks that cannot be staged may refuse translation
atomically. Existing clipboard size/entity limits still apply. These are remaining
workflow limits, not production signoff.

The full release audit remains unaccepted: 208 evidence gaps across ten gates.
Manual task U323 remains **Not tested** for the user's own acceptance. Local logs,
eight copy captures and the mixed preview are under `artifacts/appraisal-copy-20261002/`.
The delivery record there binds the pushed commit and installed executable hash.
