# Persistent measured-stroke relationships

Receipt-backed measured strokes now use the existing Dimensions and constraints
dialog for horizontal, vertical, coincident, fixed chord length, parallel,
perpendicular, fixed anchor and analytical physical arc length. Both endpoints
are selectable, including an open terminal vertex. Stable revisited vertices
resolve once; crossings and retracing remain valid loose linework.

Typed resize and vertex edits, pure-stroke movement and rigid transforms respect
persisted relations. Solver corrections append one simultaneous vertex batch,
validating final geometry without rejecting a valid edit merely because a
sequential intermediate edge would collapse. Entered quantities and original
receipts survive. Reflection is retained as a rigid operation, preserving the
appropriate signed curvature. Unchanged resize closes without a history event;
subsequent input changes invalidate that preview.

The core completes previously current, unambiguous, unauthored measured-area
consumers before sealing the candidate. Group members and outer lineage update
together; declared appraisal facts remain recorded observations. Stale,
ambiguous, authored or unavailable-phase consumers remain subject to review and
withhold qualified totals. Final hard constraints validate the completed state.
Owned annotation offsets follow rigid rotation/reflection once, including
several selected strokes sharing one annotation owner; translation retains them.
Overlapping raw geometry or owned-placement supplements are refused.

version 33 protect retained history, including relation-only bindings and
undone/deleted owners. Existing command modes compose independently and retain
legacy admission. Unsupported models remain opaque/read-only. Clipboard
remapping changes schema-owned batch references and relation bindings while
retaining unrelated metadata.
