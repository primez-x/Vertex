# Authored relationship moves and GLA visibility

Details is the third left-panel tab beside Layers and Library. Its prominent GLA
total comes from the authoritative appraisal report, with floor/area breakdowns,
dimensions, deductions, Setup and Full report. The selected ANSI Z765-2021 profile
and rule version now appear directly beneath a qualified GLA total, alongside
the pending final standards validation. The app does not claim ANSI approval.

The actual relationship-move dialog previously displayed a moved driver but
committed only its dependents. The focused native RED fixture reproduced that
failure. The desktop now rebuilds one complete command through existing typed
transform adapters, retaining both driver and dependents, boundary receipts,
dimension anchors, physical host bindings and source completion. It displays the
actual candidate and reconstructs it before publication behind the modal fence.
Independent driver moves remain usable. All saved relationship records form a
validated temporary union, exposing cross-record cycles and contradictory drivers.
Movement causes are tracked separately from physical expansion. The pure solver
and legacy dependent-only API retain their existing contract, now documented.

The independent advisor required combined graph validation, cause tracking and
geometric rather than raw transform comparison. Those corrections are included.
Native evidence lives in artifacts/room-relationship-move-20261004. The affected
checks cover Preview/Cancel/Apply, one-revision driver/dependent edits, receipts,
manual dimensions, actual hosted-door wall movement, exact Undo/Redo,
ownership-safe save/reopen, stale/read-only/invalid/conflicting refusal,
independent rotation and chains/cycles across separate relationship records.
Details coverage checks the visible ANSI profile and unresolved validation.

The final Release build and all nine affected checks pass: room relationships,
relationship geometry, legacy dependent commit, authored desktop movement,
appraisal Details, wall measurements, constraint authoring, native storage and
exchange. Root inspected the actual workspace ANSI/GLA capture and the physical
wall/room preview, then reviewed the integrated diff and interfaces. Initial
fixture compilation failures (Windows near macro, Qt child lookup and namespace)
and the invalid concurrent-wall fixture were corrected; failed records remain.
One check after a failed capture-only build ran the previous executable and is
not final evidence. Final evidence is green6-build and green6-check.

Known production gaps remain: constrained geometry beyond the existing detached
transform graph can refuse instead of solving a connected edit; splitting a
physical wall referenced by a room requires a retained logical-chain adapter;
future relationship model admission, normative ANSI validation and Apex native
compatibility are still incomplete. Technical checks are not user signoff.
