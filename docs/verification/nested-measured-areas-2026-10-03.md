# Nested measured outlines and explicit deductions

The actual measured-line detection command now opens a per-outline native
review. The graph reports analytical gross boundaries and immediate strict
containment while retaining source intervals and traversal. Inner references
are not inferred rooms or exclusions. A chosen deduction links two identified
boundaries using the existing context, TYPE, containment and union rules.

Existing IDs, names, styles and appraisal declarations survive detection.
Boundary creation and deduction links are prepared as one document transaction.
The desktop augments phase membership before preview and retains that complete
command; Apply commits it only while the source, revision and drawing context
remain unchanged. Inactive or demolished sources and definitions are excluded
from graph construction, identity matching and source qualification.

## Requirement gap check

Detection, explicit choices, combined deductions, identity preservation, source
qualification, transaction safety, storage and visible calculation/output are
covered by this change and scoped evidence. The user checklist adds U380–U383,
all initially Not tested. New nested deduction chains remain explicitly
unsupported; deeper detection alone does not establish arbitrary hole editing.

Native Apex compatibility, complete keyboard/device/integration parity, final
ANSI normative validation, clean-machine offline qualification and the unified
production gate remain unproven. This is an internal build, not the completed
production replacement. Public source and forever-free distribution remain the
user's chosen direction.
