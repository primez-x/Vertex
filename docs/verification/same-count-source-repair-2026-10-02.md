# Changed exterior geometry with reviewed references

**Replace source walls...** now accepts an altered analytical exterior with the
same number of edges. The existing reference review asks which replacement edge
or corner should carry each supported manual dimension or constraint. Equivalent
outlines retain their existing attachments directly. Changed outlines receive
fresh topology; automatic dimensions regenerate. One command retains the same
appraisal owner, facts, factors, appearance and contained deduction relationships.

The source review shows old gray and proposed blue geometry, an amber chosen
wall, quantities and readable source changes. Full source IDs are available in
a collapsed, height-bounded detail view. Cancel and stale nested reviews remain
detached from the document.

Strict version-4 redefinition requires `fresh_topology: true`, both reference
decision fields and an explicit source ID array (empty for generic redraw).
Existing wire representations are unchanged. Fresh intent requires native 17
and exchange 15, including retained undone/deleted history and imported proofs.

## Observed verification

- Baseline core rejected v4; the actual native source dialog disabled Apply for
  changed geometry with an equal edge count. Both failures were observed before
  production edits.
- Core straight/curved, authored/plain source fixtures verify explicit dimension
  and coincident-reference mapping, permitted lock removal, regenerated automatic
  dimensions, exact geometry, detached preview and atomic history. Invalid,
  missing, unused, cross-kind and colliding decisions refuse. An incompatible
  retained length lock raises `constraint_violation` without changing snapshots.
- Generic plain redraw preserves its exact topology origin without inventing
  wall provenance. Fork, imported proof, native reopening and exchange floors
  are checked. Recomputed-digest under-versioned files are rejected.
- Native Imperial/Metric straight/quarter-arc fixtures exercise actual source
  and reference dialogs: Cancel, nested unit staleness, explicit manual mapping,
  retained appraisal facts/deduction/appearance, changed area, qualification,
  fresh automatic dimensions, Undo/Redo, reopen and v4 clone/clipboard proof
  remapping. This does not certify every clone dependency behavior.
- Release build and full boundary arc, integrity, document, wall measurement,
  desktop exterior measurement, storage, exchange, boundary workflow/editor and
  canvas checks passed. Adaptive-grid checks passed actual painted/snap alignment,
  signed coordinates, construction-unit intervals and geometry preservation.
- Root inspected current source and reference dialog captures after event-driven
  layout, plus the rendered 1 cm grid. Checks ran offscreen; no human app launched.

The new checks initially had API argument and expected-error-category mistakes;
