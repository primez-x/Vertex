# Automatic exterior measurements from wall closure

The Details tab exposes GLA, category totals and each selected measured area's
analytical edge dimensions, perimeter, gross area, deductions and net area. Its
ANSI Z765-2021 profile retains whole-square-foot GLA and tenth-foot dimensions;
final normative validation remains unresolved. This is not ANSI certification.

This checkpoint addresses a separate original-scope workflow gap: closing a
physical wall outline formerly created only walls, requiring a later manual
exterior-measurement command. In an explicitly configured Appraisal workflow
with an Exterior basis, actual clicked or precise closure now creates the
source-linked measured exterior and automatic dimensions in the closing wall's
command. The manual command shares the same entity/dimension construction.

No grade, finish, access, ceiling, use or ANSI area observations are inferred.
Those declarations still determine whether the measured physical area qualifies.
Exact physical thickness and analytical curves determine the exterior outline.
The final admitted preview must retain a current wall source. Public generic
wall creation and other measurement bases do not acquire automatic area creation.

Automatic admission checks the owning property, building, floor and current design
phase across layers. Existing site/survey geometry is separate. Nested outlines,
contacts, analytical overlaps, stale measurement sources or uncertain recognition
keep the valid physical wall closure, add no speculative measurement and display
a timed explanation protected from immediate cursor-message replacement. Ordinary
operation messages can replace that notice. Architectural room boundaries remain
separate from appraisal contributors.
