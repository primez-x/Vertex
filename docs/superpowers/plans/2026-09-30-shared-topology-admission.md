# Shared topology admission

Outcome: connected endpoint editing and typed command replay enforce the same
analytical crossing, overlap, contact and winding rules. A reconstructed proof
or recomputed project checksum cannot bypass those geometry rules. Existing
valid command encodings, signed sweeps, endpoint identities, units, undo/redo
and original curve measurements remain intact.

## Ownership

- Core worker: shared constraint topology validation, authoring/document
  integration and direct command/integrity regressions.
- Persistence worker: matched entity/proof forgery with a recomputed checksum
  in project and exchange history; valid command roundtrip coverage; typed
  straight wall-only authoring, strict command envelope 4, project format 11
  and exchange format 8 compatibility gates.
- Root: dependency integration, documentation, focused builds, final review,
  Git and delivery. The organization resolver moves into the document core;
  its existing CMake target remains an interface for consumers.
- Advisor: independent challenge of topology and history admission once the
  integrated source and runtime evidence are available.
