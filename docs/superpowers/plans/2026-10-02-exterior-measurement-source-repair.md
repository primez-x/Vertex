# Repair exterior measurement sources

Replacing a perimeter wall currently strands its existing appraisal area on a
deleted source identity. Add an explicit reviewed source replacement on the
same area, preserving facts, name, appearance, deductions, dimensions and
history. Ordinary Refresh continues to use only its retained source IDs.

Ownership: the core worker owns typed redefinition/source validation and reader
format floors, plus core storage/exchange fixtures. The UI worker owns the
source-choice/review and clone consumers in main_window.cpp. Root owns the
desktop fixture, integration, documentation, Git and delivery.
Only frozen paths enter a build; all writers preserve existing work.

1. Reproduce the missing repair action with a replaced wall in a qualified
   residential exterior that has styling, facts and a garage deduction.
2. Add replayable source-ID intent to typed boundary redefinition. Independently
   derive and validate the proposed exterior, exact drawing context and retained
   deductions; retain opaque metadata and original input. Guard new persistence
   semantics in current, undone and imported states with explicit reader floors.
3. Offer a shell wall selector and old/new exterior preview, area/perimeter and
   source changes. Review changed-topology annotation references through the
   existing reference planner. Commit geometry and source rebinding atomically
   only after the user accepts the concrete proposal and context still matches.
4. Verify Imperial/Metric, straight/curved shells, Cancel/stale/invalid refusal,
   one retained measurement owner, restored appraisal quantities, complete
   Undo/Redo, save/reopen, output and format downgrade refusal. Review source
   integrity independently, fix required findings, then commit/push and deliver
   the matching local bundle. Full production acceptance remains required.

Independent approach review requires resolved target/source hierarchy, phase
eligibility and canonical elevation validation in the core, rather than trusting
UI filters. Source changes require typed intent; historical geometry replay
must remain valid after later walls disappear. Same edge count requires a unique
geometric cyclic/direction correspondence before retaining child IDs; ambiguous
mapping refuses rather than assigning by array position. Changed topology uses
explicit reference mapping. Original source v1 has no archived elevation, so
when every old wall is missing and the owner has no explicit elevation, the
original plane is unavailable; enforce a coherent replacement plane and expose
that limit in the review rather than inventing a historical measurement.
