# Curved boundary resize controls

Outcome: changing the physical length of a curved measurement edge offers the
same explicit choice to move or retain related walls/areas as a straight edge.
Saved relationships, exact curve sweep, dependent dimensions and one-command
history remain authoritative. Curve reconstruction still keeps endpoints fixed.

Root owns source, the native editor fixture, integration, documentation, Git
and delivery. A read-only scanner independently examines the wall-to-appraisal
workflow; its findings do not authorize unrelated edits or overlap these paths.

1. Reproduce the disabled related-object control in the actual boundary editor
   using a curved boundary linked to a physical wall.
2. Remove the obsolete straight-only UI restriction. Preserve solver conflict
   validation and detached preview; do not detach saved relationships to make
   an incompatible edit succeed.
3. Exercise move/retain, Cancel, Apply, exact curve length/sweep, connected wall,
   dependent dimensions, Undo/Redo and save/reopen in Imperial and Metric.
4. Review the integrated result, run affected checks, update practical user
   instructions, commit/push and deliver the matching local build. The full
   production goal and compatibility gates remain open.
