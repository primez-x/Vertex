source-bound side gesture and one Undo, under Properties44/reader267/extraction265.

   make no nonzero-slope proof claim; core qualifies those native extents.
4. Root owns controller, Document/lifetime, storage floors, CMake, documentation,
   generators, Git and native jobs. Integrate only after ownership returns.
   Canonical history requires267/265; opaque slots retain prior floors. Validate

   historical checks, inspects Plan/Site captures and reviews the integrated

   refresh source-kit inventory, check staged/unstaged diffs, then commit reviewed
   named paths, push and verify the exact remote SHA. Keep evidence and product

User authorization covers execution. Writers run no builds, native jobs, Git,
generators or external mutations; root owns integration and verification.
