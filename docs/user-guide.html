User guide

Vertex is a local Windows application for property measurement and residential or light-commercial architectural documentation. Projects, calculations, references, and output stay on the machine.

Start a project

Use Ctrl+N for a new project, Ctrl+O to open a .bldproj, and Ctrl+S to save. Save As creates a new project copy and preserves the original. The application keeps local recovery copies while a project is being edited.

Draw and furnish a room

  1. In Layers, click the layer that should own the drawing. Choose Wall in Draw and set thickness and height in Library. Click the room's corners, then its first corner to close the wall loop.
  2. Select a wall. Press Ctrl+K and choose Create room boundary from selected geometry. Name the room, then use Library > Area classes to classify it. Double-click the room to open floating Properties and read its clear area under Area calculation.
  3. Drag furniture from Library onto the plan. Select a placed symbol and use its side handles to adjust its size. Use Door or Window in Library, choose the style and dimensions, then hover over a wall and click the opening preview.
  4. Right-click a wall and choose Change length… to review its new length and connected movement. Double-click the wall to change thickness or height in Properties. An edit that leaves a door or window outside its host wall, or conflicts with the wall's material-layer thicknesses, is rejected with an explanation and leaves the drawing unchanged. A retained room whose wall sources have changed needs an explicit Tools > Repair room from walls review.
  5. A saved 2D room remains visible in the plan and can be moved, rotated, or resized with its canvas handles. To give it a 3D volume, open Room dimensions and enter its measured height and base elevation. Missing measurements are blank; Apply becomes available after both values produce a valid preview. Cancel keeps the original 2D room.
  6. For appraisal, select a perimeter wall and choose Measure exterior from walls…. Review and create the separate measurement. Use the left Details > Setup and Edit facts controls to qualify GLA. Clear room area and property GLA are separate calculations.
  7. Save, try Undo and Redo, then reopen the project and check the room, furniture, openings and measurements.
  8. Use command search for Edit sheet layout to open Sheet layout manager…. Set the plan viewport's scale and placement, then use Export selected sheet PDF or Print selected sheet (draft). Check that the whole room and its labels fit the sheet. Print at actual size to retain that scale.

Drawing in 2D

Choose Wall to draw physical walls, or Area to draw an appraisal boundary. Wall is the default. Click to place the start, then click each next endpoint. Click the original anchor to close and finish the outline, or press Esc or right-click to cancel the pending wall and finish an open wall chain; completed walls remain. Wall thickness and height are in the Library tab.

After placing the first point, type a length on the canvas and press an arrow key to add an exact horizontal or vertical edge. The floating length control also has direction buttons. Bare numbers use feet in Imperial or metres in Metric; entries such as 12 ft 6 in, 1 1/4 and 125 cm retain their exact units. Enter repeats the visibly selected direction. The 123 button expands a keypad. Escape in the length field clears that entry and returns focus to the drawing without cancelling the outline or deleting walls. Use Ctrl+arrow, Home/End or the mouse to edit text without placing an edge.

Each accepted wall is one undoable operation. While a wall chain is active, Ctrl+Z removes its last edge and resumes at the retained wall's end; Ctrl+Y restores that edge and its endpoint. Undoing every edge returns to the original anchor. Adding a different edge after Undo discards the old redo branch. If only the start anchor is present, toolbar Undo cancels that unfinished chain without changing earlier project history. Measurement edges stay in the unfinished outline until it closes. Define First still requires placing each manual dimension before entering another edge. Navigation and grid spacing never round typed lengths.

Choose Measured lines in Draw to create an open stroke or separators before defining areas. Every placed side commits immediately. While the stroke is active, Ctrl+Z removes one side and restores the pen at the previous endpoint; Ctrl+Y restores that side and its endpoint. Undoing all sides returns to the original anchor. Draw a different side after Undo to replace the abandoned redo branch. Enter, Escape or a stationary right-click finishes the stroke and keeps committed sides. Undo at an uncommitted anchor cancels only that anchor. Reopening a project does not resume drawing. To assign a closed region an area classification, select the saved linework and use Tools > Detect closed areas.

Select a finished measured stroke to use Copy, Cut, Paste or Delete through Tools, the usual keyboard shortcuts, or the canvas right-click menu. Paste is also available on empty canvas. A paste into an empty project retains the measured position; beside existing geometry it is placed to the right and selected for movement. Copies have independent identities and retain typed inputs and saved appearance. Cutting or deleting a line used by an area keeps that area's geometry and facts, but its source is stale and qualified appraisal totals are withheld. Undo restores the source. Unsupported future line models remain protected.

The measured-area review lists each closed outline, its containing parent, gross area, classification, deductions and net area. Inner outlines default to Reference only. Choose Define area for a separate area or Deduct from parent for an explicit subtraction, and classify each new area. A 100 m² outer outline with a 16 m² inner deduction has 84 m² net. Independent overlapping areas withhold valid totals; no appraisal eligibility is guessed.

Existing definitions keep their identities, names, styles and facts. Reference only keeps an existing definition unchanged. Repeat detection creates no duplicates. Only the active design phase supplies source outlines; layer eye controls do not change calculations. Apply commits the full preview, deduction links and phase membership in one undoable operation. Cancel changes nothing. Review stale measured sources before defining another area, and record actual appraisal facts in Details before using GLA totals.

With an explicit ANSI appraisal profile, the same review can define a floor, a contained room and an exclusion inside that room together. Select Deduct from parent for each contained area, including a room with the same classification as its parent. Each parent deducts the immediate child's gross footprint; an eligible child contributes its own net area. For example, outer 100 m², room 36 m² and internal void 4 m² produce outer net 64 m² and room net 32 m²: qualified GLA is 96 m², with the void excluded once. Record actual eligibility observations with Edit facts. The area labels alone do not qualify GLA. Select a measured area to edit its deduction links later; removing and restoring a link is undoable. Ordinary measurement and declared appraisal Auto-Subtract retain their existing TYPE and nesting rules.

Clone or Copy/Paste an ANSI measured parent to duplicate its complete room and exclusion graph, source lines or walls, dimensions and appearance. Copied areas use independent references; editing the copy does not edit the original. Paste into a project with a supported ANSI appraisal profile to retain nested partitions. Undo removes the complete copy in one step. A copied sloped room keeps recorded measurements but requires fresh Details > Edit facts confirmation for that room before it qualifies for GLA. Its old observation is not silently transferred to the new room. Valid stair-floor bindings follow the destination floor.

In Measured lines, D opens precise input for the starting point or next side. Choose length/heading, rise/run, a turn relative to the previous side, a world-coordinate endpoint, or one of the four analytical arc methods. Chord-based arcs default to chord length and heading plus sweep angle, signed height or arc length. Choose Endpoint X/Y if you already know the endpoint. Entered chord lengths, headings and units remain saved with the construction; tangent-based arcs use start tangent, arc length and sweep. A relative turn after a curve follows its ending tangent. Invalid values stay in the dialog with a reason so you can correct them; Cancel places nothing.

Moving focus to another control ends the current drag, including a move still waiting for its exact preview. A late result cannot apply that drag. Unfinished wall or measurement outlines and armed component placement remain available when you return. Space-to-pan releases when the canvas loses focus.

Grid spacing and snapping change together as you zoom. Imperial uses whole feet, half-feet, inches and fractional inches; Metric uses metres, centimetres and millimetres. Stronger lines mark larger intervals and the canvas scale cue shows one cell. Zooming never changes existing measurements.

With Snap on, a mouse-drawn wall or measured edge also settles on useful length increments relative to its own start, including on a diagonal. Wider views use common feet/inch or metre/centimetre increments; close views use fractional inches or millimetres. The preview and placed edge share the same effective endpoint. Exact existing endpoints and closure take precedence, and typed measurements retain their entered precision. Snap off permits free mouse placement.

Right-click and drag to pan anywhere on the canvas, including over a selected object. Panning keeps the pending drawing or placement active. A right-click without dragging cancels a pending drawing or new symbol placement; already placed walls and symbols remain. With no pending action, it opens the relevant context menu.

Rotate a selected appraisal area with its rotation handle, or use Transform selection for a numerical rotation or horizontal or vertical flip. Its retained deductions and supporting physical walls and hosted openings move together around the parent's pivot. Review the complete preview; Escape or Cancel leaves the drawing unchanged. The operation preserves object identities and appraisal totals and undoes in one step. Incompatible locked relationships or shared dependencies that would invalidate another area are refused without changing either area.

An older curved exterior may need a reviewed source refresh before using the precise group transform. Its original saved outline and history remain intact until you explicitly apply that refresh.

When redrawing an area with new corners, Review redraw references lets you keep an angle measurement and map its edges/corner to the new outline, or choose Remove for that angle. This includes automatic angle labels. Edge measurements regenerate from the new outline. Preview the choices before Apply; Cancel leaves the original area intact. One Undo restores the shape and any removed labels.

For an angled or curved wall, press D on the canvas. Before the first point, D accepts exact start coordinates. After that it offers length/heading, rise/run, relative turn, world endpoint, arc chord/angle, chord/height, chord/length and start-tangent/length/sweep. Angles require a unit such as 45 deg or pi/2. A relative turn follows the preceding wall's ending direction; after a curved wall it follows the tangent at that endpoint. Every accepted edge creates a physical wall with the chosen thickness and height. Cancel leaves the chain unchanged. The same D form remains available for measured outlines and exact Define First dimension positions.

To edit a curved wall's classification, select it and choose Edit curve…. Changing only Classification preserves the exact endpoints, sweep and arc length. You can change the curve and Classification together before applying; one Undo restores both. Hosted openings stay attached, and the wall name and other properties remain in place.

Wall endpoints authored together in the same floor, layer and design phase retain their connection. To change a wall length, use its dimensions and constraints editor and review connected movement before applying the edit.

Select a wall, then drag inside its selection frame to move it. Connected corners move together and adjoining walls adjust; the live preview includes hosted doors and windows. Ctrl-click several walls to move them together. Two straight walls meeting at an unambiguous endpoint on the same floor, layer and phase form a clean corner using each wall's thickness. The plan and its printed output omit the internal seam while retaining selectable wall geometry and the original measurement baselines. Straight partitions meeting the middle of a wall, crossing walls and three-way endpoint junctions also omit internal material lines. Exposed opening jambs and the outside wall faces remain visible. Undo restores the complete edit. Locked measurements or an opening that no longer fits stop the move and leave the project unchanged.

A click selects an existing object. Drag empty canvas to pan; drag inside an already selected object to move it. Click empty canvas once to clear a selection before starting another drawing. Use Ctrl+click to add selections and Ctrl+drag for a selection window. Double-click an object to edit its quick properties; right-click for its relevant actions.

Selection controls leave space around measurement text. Rotation and resize handles can move to clear positions, with connectors back to the object; drag their visible markers as usual. The size badge also moves to a clear position. These display adjustments do not move saved annotations or change dimensions. Printed and exported plans omit selection controls.

For a measured exterior derived from physical walls, moving a corner also reshapes its source walls. Use a corner handle or Edit boundary geometry > Vertex position for exact X/Y. The preview includes the physical consequences; the measured exterior, dimensions and GLA update together. Other exterior corners and wall thicknesses remain anchored. Partition attachments retain their relative position along the wall, and hosted openings retain their physical distance from its start. Conflicting constraints or openings that no longer fit prevent the change. Undo restores the whole edit.

Relationships on measured lines

Select a measured stroke and choose Dimensions and constraints from its right-click menu. Both endpoints of each named edge are available, including the final endpoint of an open stroke. Add fixed length, horizontal, vertical, coincident, parallel, perpendicular or fixed endpoint relationships. Fixed length measures the chord; Fixed physical arc length measures the curve. Preview connected movement before Apply.

Moving a constrained measured stroke or editing a vertex respects the saved relationships. Conflicting locks refuse the edit with an explanation. Current, unambiguous measured areas update together with their sources; ambiguous or stale sources require review in Details. Undo, Redo and reopening preserve the complete change, original entered measurements and recorded appraisal facts.

Project details and GLA

Open Details beside Layers and Library in the left panel. Above-grade finished area (GLA) and separate category totals remain available without selecting anything on the canvas. Choose Setup to enable appraisal and declare the property's basis. Expand a floor and select an area to inspect its edge lengths, perimeter, gross area, deductions and net area. Edit facts supplies observations needed for qualification; Show on canvas locates the area and Full report opens the printable calculation report. Missing facts or stale source geometry withhold totals until repaired. Hiding a layer does not change appraisal totals.

For ANSI-oriented measurement rules, choose Setup and the ANSI Z765-2021 profile. Declare inspection, measurement method and any limitations, then use Edit facts for each area's grade, finish, access and measured ceiling evidence. The main GLA uses whole square feet and its analytical edge lengths use tenths of a foot, including in a Metric workspace; metric equivalents are supplementary. ADUs and nonstandard finished areas remain separate. Missing or stale evidence is explained beside the affected area. Vertex rule checks and the unresolved final-standard validation are shown explicitly; the app does not grant ANSI approval or produce a complete UAD appraisal report.

The boundary geometry editor's proposed dimension labels and measurement review use the same profile as the canvas and printed plan. Coordinate fields and measurement inputs keep the workspace's chosen units. Changing the display does not round the stored geometry.

Appraisal measurements

To change an SVG component's colors, double-click it for quick properties and choose Colors…. Clear Use library colors, then choose Outline and Surface colors and Apply. Shading, glass, recesses and dark details remain intact. The change affects only that placed component; its size, rotation and original artwork stay unchanged. Check Use library colors again to reset. Cancel discards changes, and Undo/Redo, copy/paste, save/reopen and sheet/PDF output retain accepted colors.

To change a wall or hosted door/window's presentation, double-click it for quick properties and choose Drawing appearance…, or use its right-click appearance action. Set the outline, fill, pattern or paper line weight, then Apply. These controls leave wall thickness, opening dimensions, relationships and appraisal measurements unchanged. A hidden object remains available in Layers so you can restore its visibility. Reset to defaults followed by Apply removes only that object's custom appearance. Undo/Redo and save/reopen retain accepted changes.

For a saved plan, elevation or section, open Architectural view settings and choose Drawing appearance…. Choose the whole view or one physical object in it, then set outline, fill, pattern, line weight or visibility. Inherited styling uses global object appearance; custom view and object settings apply only to that saved view. Hidden views remain in the view selector so you can restore them. Reset clears the chosen scope. These settings survive history and reopening and use the same scene in the canvas and sheet/PDF output.

Choose Area in Draw for appraisal boundaries. Draw a boundary directly, or choose Define area before drawing when the classification and target area should be established first. Enter distances with units such as 12 ft 6 in, 3/8 in, or 4.2 m. Snap, grid, closure, bay completion, and point jumping are available from the command search.

Select a closed boundary to inspect its classification, factors, deductions, area, perimeter, and calculation provenance. Every edit is undoable with Ctrl+Z.

The grid uses the selected units and current zoom. Imperial views move through feet, half-feet, inches and fractional inches; Metric views move through metres, centimetres and millimetres. The small scale cue shows one grid cell. Grid snapping uses the same spacing. Exact object endpoints take priority, and changing zoom or units does not round existing measurements.

Choose Tools > Add length, angle or area dimension… to restore a deleted edge dimension or add another associated dimension. Choose the boundary and edge, then Add length. Length labels are placed outside the boundary by default; turn that option off to use the entered label coordinates. The dimension follows its source geometry.

Select a measured boundary and choose Edit curve… or Edit boundary geometry…. Choose an edge and a curve angle, signed height, or arc length. Negative angle or height chooses the opposite side. Angles require explicit units or a pi expression, such as 90 deg, 1.5708 rad, or pi/2; a bare number is ambiguous and cannot be applied. Arc length offers Clockwise curve. Both curve endpoints stay fixed. Review the original/proposed outlines and changed dimensions, area and perimeter before Apply. Invalid topology or conflicting locked measurements disables Apply and explains the problem.

To correct an exact corner on a completed measured boundary, choose Vertex position in the geometry editor. Choose the corner and enter its X and Y coordinates. Bare values use the workspace units; explicit units such as 2 in or 50 mm are also accepted. Review the actual candidate before Apply. Cancel preserves the outline; Apply is one undoable edit. Related locked geometry and wall-source correspondence must remain valid.

When an edited curved edge has related objects, leave Move related objects checked to update them with the boundary. Turning it off can be refused if it would leave connected geometry invalid.

To measure while drawing walls, open Details > Setup, enable appraisal calculations and choose an Exterior measurement basis. Click the wall outline's corners and return to its first point. The completed outline receives a separate exterior measurement and dimensions automatically, using the physical wall thickness. The closing wall and measurement share one Undo operation. Use Details > Edit facts to supply the observed floor and area facts; drawing a closed outline alone does not qualify it as GLA. An outline inside, enclosing or overlapping an existing measured area requires explicit measurement review. Vertex keeps those walls and explains why it did not add another measured area.

For an existing closed physical wall layout, select a wall and choose Measure exterior from walls… from its right-click menu or Tools. Connected interior partitions are excluded from the exterior perimeter. You can select a partition to find its connected shell, or Ctrl+click an explicit set of candidate walls. Review the blue exterior outline, excluded wall count, area and perimeter, then create the measurement. Straight and circular walls retain their actual geometry. This uses each wall's thickness, rather than treating its baseline as the outside face or replacing a curve with a chord.

Declare the property's appraisal workflow and the area's observed facts in Edit appraisal facts… to obtain classified square-footage totals. Double-click an area to open Properties; the facts button is directly below Classification and is also available from the area's right-click menu. The appraisal summary keeps qualification and primary totals visible; expand Details to inspect the remaining categories and contributions. The selected category and default area colors follow those declarations. Change a declared category through the facts editor; the category itself is read-only. Incomplete or invalid declarations show Unqualified. Custom area appearance and label placement remain independent of the facts. Reset to defaults restores the current declared category's appearance. Undeclared legacy areas retain manual classification editing. Valid edits to the recorded physical walls update a current exterior outline, its dimensions and appraisal totals together in one undoable operation. The area keeps its declarations, appearance and deduction links. You can select walls together with furniture and labels to move them in one operation; the preview includes the linked exterior outline even when that area is unselected. Escape cancels the complete preview, and one Undo restores the complete edit. If an outline was already stale, select it and use Refresh exterior measurement… or the source replacement review to repair it. Stale outlines cannot produce qualified appraisal totals. Open wall chains need a closed measurement boundary. Separate exterior shells must be measured individually; the app does not choose a shell solely because it is the largest. Overlapping walls, ambiguous contacts, offsets that cannot meet and unresolved near-parallel corners are refused with an explanation, leaving the current drawing unchanged.

For custom area information, open Area attributes > Details…. Enter one Name and Value per row. Use Add or Remove to change the list, then Save. Names must be nonempty and unique; invalid entries explain the problem and prevent Save. Cancel leaves the project unchanged. These custom details do not change appraisal facts or square-footage totals.

Refresh follows the perimeter walls recorded when the area was created. Replaced walls or an addition that changes the exterior require an explicit source replacement review. Overlapping building measurements cannot produce qualified totals.

To repair a stale measurement while retaining its identity, choose Replace source walls… from Tools or the measured area's right-click menu. Review the recorded and proposed outlines before Apply; Cancel leaves the drawing unchanged. Refresh continues to use the originally recorded walls, while replacement explicitly records the reviewed shell as the new source. If the outline changes, the reference planner lets you map or remove supported manual dimensions and constraints. Equal edge counts do not imply correspondence; the app does not guess by list position.

Select a contained area, right-click and choose Subtract from area to choose its compatible parent. In declared Appraisal, current area facts determine each TYPE; an older manually assigned category does not override them. Equal TYPEs and incomplete declarations cannot create a deduction. Applying a deduction retains both boundaries and updates the parent's net. Reopen the action to remove it; Undo and Redo retain the complete relationship.

Cloning or copying a supported appraised area includes its required related areas, deduction links, hosted openings, associated dimensions, appearance and fully contained constraints as one editable group. The original objects remain unchanged. Copy/paste to another project carries the required group too. Exterior measurements include their recorded source walls; if a required source is missing or stale, repair it before copying. The app refuses the copy rather than silently detaching that source. Move a copy clear of other building measurements before relying on qualified totals; overlapping areas withhold those totals. Independent copying of a parent with nested appraisal descendants is not yet supported; keep those original links intact.

Open Tools > Appraisal area report… to review the property's summary, individual areas and deductions, and qualification issues. Select an area to see gross area, requested and applied deductions, physical net, exact factor, adjusted area, perimeter, rounding and the declarations used. Show on canvas selects its source. Workspace visibility does not change totals; the saved design alternative does. Use Refresh after editing the project. Export PDF… saves the complete audit across as many pages as needed. Unqualified measurements remain diagnostics; they do not become qualified property totals.

An undeclared policy retains valid individual diagnostic measurements while withholding qualified totals. An area with malformed facts or geometry remains in the report with its issue and unavailable quantities. Select that row and use Show on canvas to locate and repair its source.

In Sheet layout manager…, choose a horizontal plan and click Create appraisal plan sheet. This adds an A3 page with a 1:100 plan and area summary, preserving existing sheets. Adjust its scale and placements for the property, then accept. The bounded summary refers to the complete report when there are more rows than fit. Cancel leaves the project unchanged; accepting is one undoable edit.

For an ANSI-oriented property, the sheet summary retains canonical whole square feet in either workspace. Metric equivalents are supplementary. The summary names the actual profile and pending final-standard validation, consistent with Details and the complete measurement summary.

Wall measurements

Double-click a wall, or right-click it and choose Wall measurement. Its measurement controls change paper text height, color, emphasis, rotation and visibility independently of the wall. Apply commits the changes through normal undo history. The value continues to follow the wall's analytical length.

Use Place measurement and click a clear canvas position. Dragging still pans; Escape cancels. Automatic restores placement while retaining style and visibility. A hidden measurement can be restored by selecting its wall and checking Visible. Saved placement follows the wall midpoint, including in rotated or reflected horizontal plans.

Reusable text

In the Library tab, use + Text to open the text library. Search names or content, or filter by category. Select a built-in entry and use Save copy to customize it, or use New for your own entry. Set its name, category, multiline text, font, height, color and emphasis, then Save. Height accepts lengths such as 3 in or 8 cm.

Choose Insert, then click the plan to place a copy. Dragging still pans; Esc cancels insertion. Double-click a placed label to edit that instance. Editing or deleting a saved library entry does not change existing project labels. Labels saved in a project remain usable without the original library file.

Library insertion places plan text at a saved model position, including in rotated plan views. Its angle stays relative to the displayed view. These labels appear in plans, not in unrelated elevation or section views.

The text library is saved locally in text-library.json in the application's Windows configuration folder. Copy that file to back it up. A damaged or unsupported file is preserved and reported; it does not prevent drawing or editing existing project labels.

Architectural objects

The Library tab offers Wall, Doorway, Door and Window. Doors and windows belong to an existing wall: hover over that wall to preview the opening, then click to place it. The door and window library entries are hosted opening variants: drag onto a wall, or double-click an entry and then click the wall. The quick insertion buttons and catalog entries use the same placement controls. Choose the opening's Style, width, height and sill before clicking its host wall. Window starts with the Fixed 1200 preset; Door starts with the Hinged 910 Left preset. Switching Style loads that preset's dimensions. Furniture and equipment remain freely placed, adjustable symbols.

Use building commands to author floors, ceilings, foundations, beams, columns, roofs, stairs, railings, assemblies, and levels. The same semantic objects drive plan, elevation, section, schedule, sheet, and native 3D views. Double-click an object for its dimensions and properties; invalid edits are rejected before the document changes.

Use Design phases and alternatives for existing, demolished, and proposed work. Use Sheets and Schedules to arrange coordinated output with independent viewport scales.

Room schedules calculate net floor area from the saved footprint and subtract its holes. A room without a measured height has no height or volume value in the schedule. Calculation details identify the source geometry and measurements; invalid geometry is reported rather than replaced by an older claimed area.

For a saved plan, elevation or section, open Architectural view settings > Drawing appearance… to change the whole view or one object's colors, fill, line weight or visibility. Exact canvas edit previews retain that view's settings, including restored walls entering its crop and their hosted doors/windows. Hidden layers, phases and excluded sources stay hidden. The numeric constraint dialog uses separate before/after comparison colors; Cancel leaves the drawing unchanged.

References and assistance

Import a PDF, PNG, JPEG, BMP, or TIFF reference from More, select the page when needed, and calibrate it from a known distance. Transform and visibility changes keep the original source bytes. Assistance can suggest tracing, dimensions, labels, or commands; suggestions are marked unverified and require an explicit acceptance before they enter project history.

In Site Plan, suggestions retain the reference's building, floor and layer. The preview and accepted outline use the building's current placement and rotation. If you change the drawing context while reviewing suggestions, request them again before accepting.

Device measurements

Select one wall, door, window, slab or room, then choose Import DISTO reading from Tools. On the Keyboard tab, enter the device name and choose the dimension to change, the device's output units and its decimal separator. Put the cursor in the reading field and send one reading from a keyboard-capable device paired in Windows. You can also type a reading. Press Enter or choose Apply.

The reading must be one positive decimal number, optionally followed by the selected unit. For example, use 12.5 with decimal feet, or 3810 mm with millimetres. Feet and inches are separate decimal choices; mixed feet-and-inches text is not a device reading. The unit must match the device's output. Vertex does not discover the device's unit setting.

The dimension and its reading are one Undo. A previous reading is retained unless you choose Replace existing measurement. Geometry that conflicts with locked dimensions or makes a door or window too large for its wall is rejected without changing the drawing. Use the Adapter file tab for an existing structured measurement file. Keyboard capture and adapter files do not establish compatibility with every DISTO model.

CAD interchange

Choose Import DXF from Tools. Before importing, review each CAD layer and choose its destination building, floor and layer. By default, source names are preserved on the active floor: matching layers are reused and missing layers are created. You can route individual source layers to existing layers on other floors. Coordinates and elevations stay as drawn; floor assignment does not reposition the imported geometry.

Imported text uses its chosen layer too. Hosted doors and windows must use the same floor as their wall, although they can use different layers. Cancel changes nothing; the complete import, including new layers, is one Undo. Original DXF bytes, source-layer mapping and import diagnostics remain in the project. Supported native wall/opening blocks remain editable; ordinary symbol linework imports as geometry. Unsupported records are reported and retained in the source asset. The adjacent fidelity report records the mapping and limitations when it can be written.

Planar CAD circles remain true curves, including circles in uniformly scaled, rotated or reflected blocks. Select an imported boundary and run Upgrade boundary editing from Commands before editing its vertices or curved edge lengths. Export keeps curved geometry and uses each label or component's assigned layer. Nonuniform circle scaling needs an ellipse and is reported rather than drawn inaccurately.

Named revisions

Open Named revisions from Tools or command search to name a stable project state. Choose From and To, including Current head, then compare. Select a floor to see its before and after drawings. Panning or zooming either pane keeps the views aligned. Overlay identifies additions, removals and changes using the displayed legend; side-by-side preserves each state's appearance. The text report includes changes across the selected project states.

A floor absent from one state produces an empty pane with an explanation. Comparison uses retained geometry and reference images; unavailable content is reported. Viewing history leaves current edits and unfinished outlines intact. Restore as new project writes a separate project, preserving the open drawing and its later work.

Output

For output at a chosen physical scale, select the output page in Sheet settings, then use Sheet layout manager… to set each viewport's scale and placement. Use Export selected sheet PDF, Print selected sheet (draft), or Export draft SVG. Print the sheet at actual size, without fitting it to the printer page, to retain the selected scale. Use Export drawing set PDF for multiple sheets. Draft sheet output carries a visible draft marker and a neighboring fingerprint file that records the influencing project and renderer inputs.

Export sketch PDF saves the visible drawing as a tightly cropped vector image for inserting into a report. Its crop and the Sketch composition guide do not establish a physical sheet scale. Use selected-sheet output when a printed measurement must match a declared scale.

Command search and shortcuts

Press Ctrl+K and type a command name. The list includes drawing, architectural, output, reference, recovery, and workspace actions. Open Keyboard shortcuts from More to edit bindings or choose the Apex-compatible subset. Conflicts and reserved text-editing keys are rejected.

Project ownership: the first editor to open a saved project owns its file identity. A second process is placed in a read-only path, and external file changes are reported before replacement.
