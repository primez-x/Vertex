User guide

Property Studio is a local Windows application for property measurement and residential or light-commercial architectural documentation. Projects, calculations, references, and output stay on the machine.

Start a project

Use Ctrl+N for a new project, Ctrl+O to open a .bldproj, and Ctrl+S to save. Save As creates a new project copy and preserves the original. The application keeps local recovery copies while a project is being edited.

Measurement workspace

Choose Measurement for appraisal and floor-plan work. Draw a boundary directly, or choose Define area before drawing when the classification and target area should be established first. Enter distances with units such as 12 ft 6 in, 3/8 in, or 4.2 m. Snap, grid, closure, bay completion, and point jumping are available from the command search.

Select a closed boundary to inspect its classification, factors, deductions, area, perimeter, and calculation provenance. Every edit is undoable with Ctrl+Z.

Architectural workspace

Choose Architectural to author walls, hosted doors and windows, floors, ceilings, foundations, beams, columns, roofs, stairs, railings, assemblies, and levels. The same semantic objects drive plan, elevation, section, schedule, sheet, and native 3D views. Use the Inspector for the selected object's dimensions and properties; invalid edits are rejected before the document changes.

Use Design phases and alternatives for existing, demolished, and proposed work. Use Sheets and Schedules to arrange coordinated output with independent viewport scales.

References and assistance

Import a PDF or raster reference from More, select the page when needed, and calibrate it from a known distance. Transform and visibility changes keep the original source bytes. Offline assistance can suggest tracing, dimensions, labels, or commands; suggestions are marked unverified and require an explicit acceptance before they enter project history.

Output

Use Print preview, Export draft PDF, or Export draft SVG. Choose the paper size in the compact toolbar and adjust sheet viewports for independent scales. Draft output carries a visible draft marker and a neighboring fingerprint file that records the influencing project and renderer inputs.

Command search and shortcuts

Press Ctrl+K and type a command name. The list includes drawing, architectural, output, reference, recovery, and workspace actions. Open Keyboard shortcuts from More to edit bindings or choose the Apex-compatible subset. Conflicts and reserved text-editing keys are rejected.

Project ownership: the first editor to open a saved project owns its file identity. A second process is placed in a read-only path, and external file changes are reported before replacement.
