# Editing loose measured lines

Make supported measured strokes available to the existing native Copy, Cut,
Paste and Delete commands. Preserve typed construction receipts, derived
edits, opaque metadata and presentation. A paste owns fresh stroke, segment
and vertex identities and belongs to the active destination layer. In an
empty destination it retains its measured location; beside existing geometry
it uses the existing nonoverlapping measured-copy placement.

The required entity flag protects reader compatibility, not a user's ability
to remove a known supported measured stroke. Removing a source does not erase
its dependent area observations: those keep geometry and facts, become stale
and withhold qualified appraisal totals. Undo restores the original source.
Other required project owners and unsupported stroke models remain protected.
Clipboard publication and document mutations follow existing atomic commands.

Root owns desktop implementation, CMake, documentation, Git and installation.
The test worker owns only the new measured-line clipboard desktop test. The
advisor reviews source and reference integrity without writing. All native
writers freeze throughout every root-owned build and native execution.

First reproduce the unsupported native clipboard action. Verify native
actions, cross-project and empty-project paste, fresh identities, typed and
edited geometry, preserved source state, Cut/Delete, shared-source staleness,
Undo/Redo, save/reopen, unsupported/read-only refusal and presentation. Run
the relevant registered desktop/core checks, inspect the integrated diff,
commit/push with remote verification and deliver an installed checkpoint.
The full production and compatibility gate remains open.
