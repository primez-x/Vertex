# Nested measured area definition

Implement the missing appraisal drawing workflow without guessing area use or
silently counting an inner outline twice. Each analytical closed outline keeps
its original source lineage and gross boundary. Detection identifies its
immediate containing outline; the user chooses reference only, a separate area,
or subtraction from that parent and supplies its classification.

Core graph ownership: the graph worker owns geometry, parent relationships and
graph regressions. Desktop ownership: the desktop worker owns the actual native
detection review and interaction tests. Root owns definition admission,
integration, source-freshness regressions, documentation and all verification.

Reuse existing area identities and declarations. Cancel commits nothing; Apply
commits the exact preview under a revision/context guard. Boundaries and links
are a single undoable transaction. Existing subtraction rules reject nested
deduction chains; detection itself may report deeper nesting. Independent
overlapping areas do not authorize a plausible GLA: normal appraisal overlap
and missing-fact checks remain mandatory.

Verify outer 100 m² and inner 16 m² as reference-only gross 100 or explicit net
84, different classified contributions counted once, re-detection identity,
cancel/stale input, undo/redo, source edits, native save/reopen and PDF output.
Inspect the native review and Details panel. Preserve the full production plan;
this is one internal checkpoint, not Apex compatibility or ANSI certification.
