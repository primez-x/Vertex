# Independent copies of nested appraisal areas

Enable the actual Clone and Copy/Paste commands for complete ANSI floor, room
and exclusion graphs. Every copied owner and geometry dependency gets an
independent identity. Shared descendants are copied once. Immediate child
gross footprints, numerical observations, appearance and bound dimensions
remain intact; one command provides atomic Undo/Redo.

Root owns desktop production changes, CMake registration, integration,
verification, documentation, Git and package installation. The dedicated test
worker owns only `tests/nested_appraisal_copy_desktop_tests.cpp`. A read-only
advisor challenges observation revocation and graph admission. Native writers
freeze throughout every root-owned native build and execution.

Source Copy/Clone admission uses the actual source policy and shared ANSI
partition validator. Paste admission uses the actual destination policy and
ownership; the existing geometry clipboard payload does not certify a source
policy. Supported ANSI V1/V2 permits complete nested graphs. Other workflows
retain their existing one-level rules. Stale geometric sources, unavailable
phase dependencies, cycles and contradictory physical owners are refused.

A copied sloped room retains raw measurements and the original geometry hash
but loses its room observation anchor. An existing confirmation flag becomes
false; V1's absent flag remains absent. Even a zero-offset copy with an equal
digest must be unqualified until actual Facts reconfirmation. Below-five-foot
source IDs refer to the copied leaves. Valid stair ownership follows the
destination floor; a contradictory old binding must not become valid through
coincident destination IDs. Unknown metadata is preserved.

Facts reconfirmation validates retained nested links through the shared
candidate-overlay validator. The leaf-only restriction applies specifically
to observed below-five-foot boundaries, not every general exclusion.

Verification starts from the observed native Clone refusal. Focused checks
exercise Clone, clipboard, cross-floor/project destination admission, fresh
dependencies, qualified totals, withheld sloped observations, actual Facts
reconfirmation, mixed layer ownership, stale sources, cycles, history,
save/reopen and report output. Inspect actual native captures, run affected
registered checks and `git diff --check`, review the integrated diff, then
commit/push and observe the installed executable. Preserve failed evidence.

This fixes a concrete Apex replacement workflow gap. It does not establish
native Apex compatibility, final ANSI standards validation or complete
production acceptance. The full accepted product goal remains active.
