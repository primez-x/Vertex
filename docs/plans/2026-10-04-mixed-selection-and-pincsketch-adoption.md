# Mixed selections and PincSketch adoption

The production objective remains the complete Apex replacement and both Vertex
workspaces. These changes close concrete drawing and appraisal workflow gaps;
they do not constitute production acceptance.

- Root: desktop mixed-selection partition, genuine mouse regression, live GLA
  access, PincSketch inventory/comparison and user checklist, CMake, generators,
  native verification, Git and delivery.
- Core worker: append envelope 16 to the existing connected command. Compose
  independent rigid and connected proofs against the same original source;
  reserve complete dependency ownership and merge only disjoint results.
- Persistence worker: retained-history native floor 42, extraction 40, strict
  reader/package handling. Old command envelopes retain their meaning.

  Vertex comparison. Independent advisor: new replay and persistence authority.

Whole-source movement preserves every attached callout's automatic/manual
placement. Explicit partial-source callout movement becomes manual. Preview,
commit, Undo/Redo and reopen reconstruct the same atomic result. Existing fixed
anchors cannot be rewritten by the new mixed operation. A relationship spanning
the two ownership lanes refuses the operation until a combined solver exists;
that remaining capability stays in the final scope.
