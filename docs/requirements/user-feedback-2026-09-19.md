# Vertex first user review — 19 September 2026

These twelve user-reported problems take priority over internal acceptance counts.
Status: fixes in progress; none accepted by the user yet.

| # | Reported problem | Manual acceptance |
|---|---|---|
| 1 | Select has no drag-selection feedback. | Drag a visible selection rectangle; release selects the enclosed drawing objects. |
| 2 | Drawing cannot be finished with the mouse; Escape loses the shape. | Click successive corners, then click near the first corner to close and retain the shape. Enter/right-click offers a discoverable finish path. Undo reverses the committed operation. |
| 3 | Drawing layer is truncated and redundant; adding buildings/floors/layers is undiscoverable. | Add and name a building, floor and layer from the navigator, select the destination, and draw into it. |
| 4 | Design phase offers only an unexplained existing baseline. | Remodeling alternatives have a clear purpose and an accessible management command in 3D mode. |
| 5 | Visibility labels and Show all/status text waste space. | Eye controls show and toggle each floor/layer's visibility without redundant status prose. |
| 6 | Internal records appear as Unassigned / unresolved drawing objects. | Internal annotation/model/sheet storage records are absent from the drawing hierarchy; real labels, symbols and unresolved objects remain accessible. |
| 7 | 2D/3D mode selection is buried; 2D exposes irrelevant 3D controls. | A prominent 2D/3D selector switches mode; 2D has simple drawing controls and hides architectural operations. |
| 8 | Top toolbar is too condensed and cryptic. | Primary file commands have readable names and usable targets within a compact single row. |
| 9 | Overview map appears to do nothing. | Toggle shows a visible overview, with a viewport indicator and useful navigation. |
| 10 | Snap icon is unclear. | Grid snap uses a recognizable magnet and clear checked state. |
| 11 | No visible component library. | A visible searchable symbol library exposes furniture, fixtures and other symbols; users can place, select and resize them in 2D. |
| 12 | Right inspector and unexplained keypad waste space; tools belong above the drawing. | Merge contextual object properties with the left navigator, make the left panel resizable/collapsible, remove the right panel, and move canvas tools into a horizontal strip above the drawing. Show measurement entry when drawing. |

Build to review: pending updated preview.

Record user results against the issue numbers above. A code change or successful build alone does not close an issue.
