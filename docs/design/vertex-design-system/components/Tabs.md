# Tabs

Tabs switch between views inside a panel (e.g. Areas / Rooms / Notes).

- **Provide:** `tabs` (`id`, `label`, optional `count`), `value` + `onChange` or `defaultValue`, and a `label` for the tablist.
- The selected tab gets `ink` text and a 2px `accent` underline; others are `ink-muted`.
- Arrow keys move between tabs. Keep labels to one or two words; at most five tabs per panel.
